Hugging Face AI

Use Hugging Face's hosted AI models to generate high-quality music from text prompts. Get a free API token from huggingface.co/settings/tokens. Your free account includes $0.10 monthly credits — enough for several music generations! We use MusicGen-Small by Meta.

Browser note: The Hugging Face API may not work directly from your browser due to CORS restrictions. If generation fails, you'll get a fallback. For best results, use a free CORS proxy like corsproxy.io (paste the API URL there to test). Or just let the app fall back to browser-based generation — it still works!

Validates your token, no credits used
